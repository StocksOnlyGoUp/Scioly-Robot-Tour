# Scioly-Robot-Tour
Hey guys! This is a code to control 28BYJ-48 stepper motors and Uln2003 drivers simultaneously. The code was used on a Science Olympiad robot tour build using mecanum wheels for the 2024-2025 season
For wiring, visit this website for the first motor: https://lastminuteengineers.com/28byj48-stepper-motor-arduino-tutorial/
Repeat the same directions for the other motors, but using the arduino mega pins specified in the code's setup.
For power, I used 8 1.5v AA batteries connected in series such that 12v is supplied. On a breadboard, I connected the batteries to the power rails and connected the motor drivers to them.
